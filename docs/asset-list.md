# Asset list for the shoot

For the creative agency (or in-house photographer). MOM action: share the asset list and video dimensions.

Until the shoot arrives, the site uses the current store photos as placeholders. No AI-generated images.

## Rules for every asset

- **Real hands first.** Wherever the product appears, a real hand comes first; plate shots come second.
- **Video works muted.** No voice-over needed; any instruction is shown on screen. Every video needs a poster frame (a still exported from the video, same ratio).
- **Safe area.** Keep the nails and any on-screen text in the centre 80% of the frame. The site crops slightly on some phones.
- **Calm background.** Plain, light, warm backgrounds that sit well on cream (#F4EAE0). No props that compete with the nails.
- **Delivery.** Send the highest-quality master. Vistaar compresses for the web. Name files `slot_product-handle_skin-tone_01.ext`.
